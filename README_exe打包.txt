===============================================
  ANSA网格优化器 Windows exe打包快速指南
===============================================

版本: 0.2.0
创建日期: 2025-08-30
作者: Chel

🚀 一键打包
===============================================

1. 确保在Windows系统上运行
2. 双击执行: build_exe.bat
3. 等待打包完成(约5-10分钟)
4. 在dist/目录找到: ansa-mesh-optimizer.exe

📋 环境要求
===============================================

- Windows 10/11 (64位)
- Python 3.8+
- 至少4GB内存
- 至少2GB磁盘空间

🔧 如果遇到问题 (重要!)
===============================================

如果 build_exe.bat 窗口闪退:
1. 【推荐】运行: build_exe_debug.bat (调试版本)
2. 【或者】右键 build_exe.bat → 编辑 → 双击运行
3. 【或者】在命令提示符中运行: build_exe.bat

其他常见问题:
1. 确保Python已正确安装并在PATH中
2. 运行: python --version (检查版本)
3. 运行: python src/main.py --help (测试项目)
4. 以管理员身份运行脚本
5. 查看 Windows打包说明.md 获取详细帮助

🧪 测试exe文件
===============================================

双击执行: test_exe.bat

或手动测试:
dist\ansa-mesh-optimizer.exe --version
dist\ansa-mesh-optimizer.exe --help
dist\ansa-mesh-optimizer.exe info --check-deps

📦 主要文件说明
===============================================

build_exe.spec     - PyInstaller配置文件(核心)
build_exe.bat      - 一键打包脚本
test_exe.bat       - exe功能测试脚本
Windows打包说明.md - 详细说明文档

🎯 预期结果
===============================================

- exe文件大小: 150-200MB
- 首次启动时间: 3-5秒
- 后续启动时间: 1-2秒
- 支持所有原程序功能

💡 使用建议
===============================================

1. 在虚拟环境中打包避免依赖冲突
2. 首次打包可能需要较长时间下载依赖
3. 生成的exe可直接分发，无需安装Python
4. 支持Windows 10/11，不支持Windows 7/8

如有问题请查看详细文档: Windows打包说明.md
